# Focus App

An iPhone app for discipline, focused work, and intentional screen-time control.

> Control your phone instead of letting your phone control you.

## Planned features

- Timed and scheduled app blocking
- Customizable unlock challenges
- Countdown and interval timers
- Focus sessions that block selected distractions
- Daily and weekly progress
- Confirmed emergency unlocks

## Technical direction

The app will be built natively with SwiftUI and Apple's Screen Time frameworks:

- Family Controls
- Managed Settings
- Device Activity
- Managed Settings UI
- SwiftData

The first release target is a private TestFlight build, followed by App Store preparation after the core workflows have been validated on a physical iPhone.
